# AI Test Case Generator (LLM-Based)

## Overview
An AI-powered tool that generates structured test cases from requirements and performs log-based root cause analysis using LLMs.

## Features
- Automated test case generation (positive, negative, edge)
- JSON structured output
- Log analysis for RCA
- Streamlit UI
- CI/CD ready

## Use Cases
- QA automation acceleration
- Large-scale system validation
- GPU/cluster reliability testing (simulated)

## Tech Stack
- Python
- OpenAI API
- Streamlit

## Future Enhancements
- Kubernetes integration
- GPU telemetry analysis
- CI/CD auto-triggered test generation
